# 🎲 DicePlot

SillyTavern 확장. AI가 "결과가 불확실한 장면"에 판정 태그를 붙이면, **다음 생성 직전에 JS가 주사위를 굴려** 결과 지침을 컨텍스트 맨 아래에 넣어줍니다.

- 주사위는 AI가 아니라 확장이 굴립니다. AI 추가 호출은 없습니다.
- AI는 결과를 정하지 않고, 유저 행동이 어떤 분류인지만 고릅니다. 분류별 결과는 확장이 미리 계산해 둡니다.

## 설치

SillyTavern → 확장(Extensions) → **Install extension** → 아래 주소 붙여넣기

```
https://github.com/kkkangkkang-creator/ST-DicePlot
```

설치 후 채팅 입력창 옆 **요술봉 메뉴**에 `🎲 DicePlot: 켜짐/꺼짐` 버튼이 생깁니다. 누를 때마다 켜고 꺼집니다. 세부 설정은 확장 패널의 **🎲 DicePlot**에 있습니다.

AI에게 보내는 지침, 결과 문구, 태그의 `action`·`stake` 값은 모두 영어가 기본입니다.

## 동작 흐름

1. **AI 응답 N**: 장면에 불확실한 도전이 있으면 끝에 태그를 남김
   ```
   <check action="경비 통과" dc="13" stake="경비에게 발각"/>
   ```
2. **유저 입력**: 평소처럼 행동을 입력
3. **생성 직전**: 확장이 d20을 두 개 굴리고, 분류별 결과를 계산해 맨 아래에 주입
4. **AI 응답 N+1**: 유저 행동을 분류하고 그 결과대로 서술한 뒤, 근거를 남김
   ```
   <judged as="Advantage" why="카드 설정: 재벌 3세"/>
   ```

태그는 채팅 화면에서 숨겨지고, 대신 메시지 아래에 작은 배지로 표시됩니다.

## 유저 판정과 캐릭터 판정

| | `who="user"` | `who="char"` |
|---|---|---|
| 언제 | 장면이 유저에게 도전을 던졌을 때 | 캐릭터나 NPC가 불확실한 행동을 막 하려 할 때 |
| 판정 대상 | 유저의 다음 행동 | 캐릭터의 그 행동 |
| 결과가 적용되는 시점 | 유저가 입력한 뒤의 응답 | 바로 다음 응답 (유저 입력이 없어도 됨) |
| 예시 | 경비 통과, 상인 설득, 무너지는 다리 | 캐릭터의 거짓말, NPC의 기습 |

캐릭터 판정을 건 응답에서는 AI가 결과를 쓰지 않고 시도 직전에서 멈추도록 지침에 들어가 있습니다.

### 입력 없이 보내기만 눌렀을 때

- **캐릭터 판정이 걸려 있으면:** 바로 굴려서 이번 응답에 결과를 적용합니다. 이렇게 처리된 판정은 다시 굴리지 않습니다.
- **유저 판정이 걸려 있으면:** 유저가 아직 행동하지 않았으므로 굴리지 않습니다. 판정은 대기 상태로 남았다가, 유저가 다음에 메시지를 보낼 때 굴립니다. 장면이 이미 넘어갔다면 `/dp-cancel`로 취소하세요.

## 판정을 거는 기준

결과가 **불확실하고**, 실패하면 이야기가 **의미 있게 달라질 때만** 겁니다. 기본 지침에 아래 사례가 들어 있습니다.

- **판정 O:** 경비가 지키는 문, 화난 상인 설득, 무너지는 다리, 독이 퍼지는 상처, 추격전, 경보가 울리기 전 금고 열기, 캐릭터의 거짓말, NPC의 기습
- **판정 X:** 메뉴 주문, 잠기지 않은 문, 친한 캐릭터와의 잡담, 고백이나 데이트 신청에 대한 캐릭터의 반응(캐릭터성으로 정함), 다시 하면 그만인 일
- **전투:** 매 공격마다 걸지 말고 흐름을 바꾸는 결정적인 순간에만. 쿨다운 1~2를 추천합니다.

## 분류와 주사위

| 분류 | 의미 | 사용하는 주사위 |
|---|---|---|
| 압도적 우위 | 확정된 설정상 사실상 장애물이 아님 | 주사위 없이 자동 성공 |
| 우위 | 확정된 자원·능력·상황을 직접 활용 | 두 개 중 높은 값 |
| 평범 | 특별한 이점도 불리함도 없음 | 첫 번째 값 |
| 불리 | 설정상 서투름, 준비 부족, 무리한 방법 | 두 개 중 낮은 값 |
| 무관 | 판정과 상관없는 행동 | 판정 무시 |

결과 구간 (기본값, 부분 성공 범위 4):

| 주사위 | 결과 |
|---|---|
| 20 | 대성공 |
| DC 이상 | 성공 |
| DC-4 ~ DC-1 | 부분 성공 (대가를 치름) |
| DC-5 이하 | 실패 |
| 1 | 대실패 |

분류 근거는 **카드, 페르소나, 이전 대화에서 이미 확정된 사실만** 인정하도록 지침에 들어가 있습니다. 백만장자가 돈을 쓰면 우위가 되지만, 이번 입력에서 갑자기 "사실 나 마법 쓸 줄 알아"라고 하면 근거로 쳐주지 않습니다.

## 슬래시 커맨드

| 커맨드 | 설명 |
|---|---|
| `/dp-check dc=13 stake="경비에게 발각" 담 넘기` | AI 태그 없이도 다음 생성에 판정을 강제로 겁니다 |
| `/dp-check who=char dc=12 stake="들통남" 거짓말` | 캐릭터 판정을 강제로 겁니다 |
| `/dp-cancel` | 대기 중인 판정을 취소합니다. 이미 굴린 결과가 있으면 지웁니다 |

## 설정

| 항목 | 기본값 | 설명 |
|---|---|---|
| 사용 | 켬 | 전체 on/off |
| 태그 숨기기 | 켬 | 채팅 화면에서 `<check>`, `<judged>` 숨김 (저장된 원문은 유지) |
| 판정 배지 표시 | 켬 | 메시지 아래에 판정, 주사위, 분류 결과 표시 |
| 굴릴 때 알림 | 켬 | 주사위 굴린 순간 토스트 표시 |
| 스와이프 시 다시 굴리기 | 끔 | 끄면 스와이프해도 같은 주사위를 씀 (리롤 방지) |
| 부분 성공 범위 | 4 | DC보다 이만큼 낮아도 부분 성공 |
| 쿨다운 | 0 | 판정 후 N턴 동안 새 판정 무시 |
| 판정 태그 지침 | | AI가 언제 태그를 붙일지 정하는 규칙. 위치와 깊이 지정 가능 |
| 결과 주입 템플릿 | | `{subject} {action} {dc} {stake} {d1} {d2} {outcomes}` 사용 가능 |
| 분류 기준, 결과 문구 | | 자유롭게 수정 가능. "기본값으로 되돌리기" 버튼 있음 |

## 데이터 저장 위치

- 굴린 주사위: 결과 응답 바로 앞 메시지의 `extra.diceplot` (보통 유저 메시지, 입력 없이 진행한 캐릭터 판정이면 그 AI 메시지). 그래서 스와이프해도 유지됨
- 수동 판정, 취소 상태: 채팅 메타데이터
- 설정: 확장 설정 (전역)

프롬프트로 보낼 때는 과거 메시지의 태그를 모두 빼고 보내므로, 태그가 토큰을 차지하거나 AI가 태그를 남발하도록 학습되는 일을 줄입니다.
